# Group 8 HW3 — Mobile Presentation Reader

Mobile-friendly English presentation script for **Q3**, **Q5**, and **13 Q&A questions**.

**Live website:** https://paul931130.github.io/group8-hw3-presentation/

The site is contained in [`index.html`](./index.html), with no build tools or dependencies.

## Publish with GitHub Pages

1. Open [Repository Settings → Pages](https://github.com/paul931130/group8-hw3-presentation/settings/pages).
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, then click **Save**.

GitHub Pages will then publish the website at the URL above. Future updates to `index.html` on `main` will be published automatically.
